# Super Sonic Grid Maker V8 — Tile Edition

Application PWA autonome, pensée d'abord pour iPhone.

## Principe
- Un morceau est composé de sections.
- Chaque mesure est une tuile indépendante.
- Édition directement dans la tuile.
- Double-clic / double-tap pour ouvrir l'éditeur détaillé.
- Poignée ⠿ pour déplacer une tuile.
- Duplication, suppression, copier/coller, annuler/rétablir.
- Tuiles modèles : ii–V–I, I–VI–II–V, turnaround, blues, vamp, pop.
- Subdivisions 1 / 2 / 4 avec diagonales.
- Affichage Accords / Degrés.
- Pré-écoute audio et boucle.

## Exports
- SVG vectoriel sur fond blanc.
- PNG / JPEG haute définition sur fond blanc.
- PDF / impression via une mise en page A4 dédiée.
- Texte.
- Projet `.grid` réimportable.
- iReal Pro.
- MusicXML.

## Installation Netlify
Déposer directement le contenu du ZIP à la racine du site :
`index.html`, `manifest.webmanifest`, `sw.js`, `icons/`, `assets/`.
